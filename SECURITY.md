# Security Policy

## Scope

This repository contains one Homebrew formula. It installs claude-fix from a
pinned, tagged release tarball verified by SHA-256. It runs no code of its own
beyond the formula.

## Supported versions

Only the formula on main is supported. It tracks the latest claude-fix release.

## Reporting a vulnerability

Open an issue at https://github.com/sarhej/claude-fix/issues with steps to
reproduce. For anything you would rather not post publicly, contact the author
on LinkedIn: https://www.linkedin.com/in/cto-mentor-architect

Expect a first response within seven days. This is a personal project, not a
funded one.
